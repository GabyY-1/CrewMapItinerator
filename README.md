# CrewMapItinerator

Éditeur d'itinéraires pour The Crew 2, en français.

## Démarrage

Ouvrez `index.html` dans un navigateur ou déployez ce dépôt comme site statique (GitHub Pages, Vercel, Netlify).

## Carte

La carte officielle du jeu n'est pas fournie ni reproduite dans le dépôt. Utilisez **Importer une carte** pour afficher une capture personnelle que vous êtes autorisé à utiliser. Les points de passage s'ajoutent ensuite en cliquant sur la carte. Sans image importée, un fond quadrillé sert d'espace de préparation. Les positions sont relatives à l'image.

## Fonctionnalités

Création, modification et suppression d'itinéraires, étapes avec description/catégorie/validation, réorganisation, progression, mode de consultation, zoom et déplacement de la carte, export/import JSON, sauvegarde locale dans le navigateur, photographie de validation facultative, interface responsive.

Aucune position, route ou donnée du jeu n'est prétendue officielle, et aucun itinéraire fictif n'est injecté.
